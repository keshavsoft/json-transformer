Document 4 — Adding Another Node

The previous example had two root nodes. Now we add a third: product.

Nothing in the traversal code changes. We only change the source structure and describe the new node with an instruction.

1. The Original Source

{
  "customer": {
    "name": "Keshav"
  },
  "order": {
    "id": "ORD-101"
  }
}

2. Add One More Root Node

{
  "customer": {
    "name": "Keshav"
  },
  "order": {
    "id": "ORD-101"
  },
  "product": {
    "code": "P-100"
  }
}

We have simply added product. The traversal does not need to know in advance that this node was added.

3. Add Its Instruction

{
  "customer": {
    "transform": "logPath"
  },
  "order": {
    "transform": "logPath"
  },
  "product": {
    "transform": "logPath"
  }
}

Now when traversal reaches product, it finds its instruction, understands it, and continues the exact same process.

Source changes → Instruction changes → Traversal remains unchanged

4. The Same Function

function logPath(value, path) {
  console.log("I am here in the tree:", path, value);
}

We did not create another function for product. The same external function is used.

5. Runtime Result

I am here in the tree: customer.name Keshav
I am here in the tree: order.id ORD-101
I am here in the tree: product.code P-100

The Point

Adding a node does not require changing the traversal algorithm. The source describes the structure and the instructions describe what should happen at that structure.

The engine simply keeps doing the same thing: traverse the source, seek the applicable instruction, understand it, and act on the source.

The structure changed. The traversal did not.
