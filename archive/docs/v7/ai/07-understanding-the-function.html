Document 7 — Understanding the Function

The traversal engine knows where it is in the source.
The function receives that information and decides what to do with it.

1. We Already Have the Tree

The previous documents showed how a source structure can be traversed according to an instructions object, and that a function can be attached to the resulting leaves.

Now we will look specifically at the function itself.

2. The Function Is Supplied From Outside

The traversal engine does not need to know what the function actually does. The application supplies the function: 

function inspect(value, path, source, instruction) {
  console.log("Value:", value);
  console.log("Path:", path);
  console.log("Source:", source);
  console.log("Instruction:", instruction);
}

The central question is: what does each argument represent?

4. The First Input — value

value is the actual data found at the current location in the source: 

{
  "customer": {
    "name": "Keshav"
  }
}

If the current location is customer.name, then: 

value === "Keshav"

This answers: what is present here?

5. The Second Input — path

path tells the function where the current value was found in the tree: 

path === "customer.name"

The value tells us what we found; the path tells us where we found it.

6. The Third Input — source

source represents the complete, root data structure being traversed: 

{
  "customer": {
    "name": "Keshav",
    "email": "keshav@example.com"
  },
  "order": {
    "id": "ORD-101"
  }
}

Even though the function may currently be operating on customer.name, it can access the complete source when broader cross-referencing context is required.

7. The Fourth Input — instruction

instruction represents the recipe directive that caused the function to be invoked at this location: 

{
  "transform": "inspect"
}

The function therefore knows not only the data and its location, but also why it was called.

8. Putting the Four Inputs Together

function inspect(value, path, source, instruction) {
  // 1. What is here?
  console.log(value);

  // 2. Where is it?
  console.log(path);

  // 3. What is the complete source?
  console.log(source);

  // 4. Why was this function attached here?
  console.log(instruction);
}

9. The Function Does Not Traverse

The function itself does not walk through customer, then name. The traversal engine has already done that work.

Source → Traversal → Current location reached → Function receives the 4 inputs
