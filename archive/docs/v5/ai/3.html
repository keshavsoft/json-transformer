Document 3 — See It Working

Let us look at the simplest working example of source-driven traversal. We start with a source structure containing two root nodes: customer and order.

1. The Source Structure

The source represents the actual data structure:

{
  "customer": {
    "name": "Keshav"
  },
  "order": {
    "id": "ORD-101"
  }
}

2. The Instructions Object

The instructions tell the engine what should happen when those locations are reached: 

{
  "customer": {
    "transform": "logPath"
  },
  "order": {
    "transform": "logPath"
  }
}

3. The Function

The function provides the behavior. It does not know how to traverse the tree—it only executes at the leaves: 

function logPath(value, path) {
  console.log("I am here in the tree:", path, value);
}

4. The Traversal in Action

The engine steps through the source from root to leaf:

1. Encounter customer → Lookup instruction → Attach logPath
2. Encounter order → Lookup instruction → Attach logPath

5. Runtime Execution Result

When the resulting object is invoked, it produces:

I am here in the tree: customer.name Keshav
I am here in the tree: order.id ORD-101

6. The Key Takeaway

The engine walked the source, consulted the instructions, and bound the external function to every instructed leaf.
