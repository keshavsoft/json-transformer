Real-World Examples

Transforming complex Tally stock items and batch allocations into clean REST JSON.

The Scenario: Tally XML Stock Items & Batches

When fetching stock items with batch allocations from TallyPrime, the raw XML-converted JSON contains uppercase keys, XML attributes (@_TYPE), text objects (#text), and verbose list names like BATCHALLOCATIONS.LIST.

1. The Food: structure.json (Raw Client Data)

{
  "STOCKITEM": [
    {
      "BASEUNITS": {
        "#text": "kgs",
        "@_TYPE": "String"
      },
      "@_NAME": "0.09/30mm",
      "@_RESERVEDNAME": "",
      "BATCHALLOCATIONS.LIST": {
        "GODOWNNAME": "Main Location",
        "BATCHNAME": "Navratan-Rs.1210/-",
        "OPENINGBALANCE": "-9.250 kgs",
        "OPENINGVALUE": 11100,
        "OPENINGRATE": "1200.00/kgs"
      }
    }
  ]
}

2. The Recipe: data.json (Transformation Directives)

{
  "transform": {
    "STOCKITEM": {
      "alterKey": "StockItems",
      "transform": {
        "BASEUNITS": {
          "alterKey": "Units",
          "valueKey": "#text"
        },
        "@_NAME": { "alterKey": "Name" },
        "@_RESERVEDNAME": { "alterKey": "ReserveName" },
        "BATCHALLOCATIONS.LIST": {
          "alterKey": "Batches",
          "valueType": "array",
          "transform": {
            "GODOWNNAME": { "alterKey": "godownName" }
          }
        }
      }
    }
  }
}

3. The Code

import transform from "@keshavsoft/json-transformer";
import structure from "./structure.json" with { type: "json" };
import recipe from "./data.json" with { type: "json" };

const result = transform(structure, recipe);
console.log(result.StockItems[0]);

4. The Result: Clean, Idiomatic API JSON

{
  "StockItems": [
    {
      "Units": "kgs",
      "Name": "0.09/30mm",
      "ReserveName": "",
      "Batches": [
        {
          "godownName": "Main Location"
        }
      ]
    }
  ]
}

Notice what happened:

  • structure.json was completely untouched (100% immutable).
  • STOCKITEM became StockItems.
  • BASEUNITS["#text"] was unwrapped into a clean string "kgs".
  • BATCHALLOCATIONS.LIST was renamed to Batches, forced into an array, and pruned to only include godownName.
  • All unrequested raw XML fields were cleanly eliminated.
