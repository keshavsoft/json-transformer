Directives Reference

Declarative instructions supported inside the recipe JSON.

Summary Table

Directive Type Description
alterKey string Renames the matching source property on the output object.
transform object Defines nested transformation directives for child objects or arrays.
valueKey string Unwraps a specific child property from an object (e.g. #text).
valueType "array" Forces the processed value to always be wrapped in an array.

1. alterKey

Renames an incoming property to a clean, domain-specific name on the output.

// Recipe
{
    "transform": {
        "STOCKITEM": { "alterKey": "StockItems" }
    }
}

// Input:  { "STOCKITEM": [...] }
// Output: { "StockItems": [...] }

2. transform

Nests instructions for child structures. When an incoming node is an object or array of objects, transform defines what to alter inside those children.

// Recipe
{
    "transform": {
        "STOCKITEM": {
            "alterKey": "StockItems",
            "transform": {
                "NAME": { "alterKey": "Name" },
                "BASEUNITS": { "alterKey": "Units" }
            }
        }
    }
}

3. valueKey

XML-to-JSON parsers often produce nested text objects like { "#text": "Main Location", "@_TYPE": "String" }. valueKey extracts the raw text directly, eliminating unnecessary nesting.

// Recipe
{
    "transform": {
        "GODOWNNAME": {
            "alterKey": "godownName",
            "valueKey": "#text"
        }
    }
}

// Input:  { "GODOWNNAME": { "#text": "Main Location" } }
// Output: { "godownName": "Main Location" }

4. valueType

Ensures consistent data types. If an upstream service returns a single object instead of a list when there is only one item, valueType: "array" normalizes it into a list.

// Recipe
{
    "transform": {
        "BATCHALLOCATIONS.LIST": {
            "alterKey": "Batches",
            "valueType": "array"
        }
    }
}
